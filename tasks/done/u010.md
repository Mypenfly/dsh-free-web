# u010 · 引擎勾选页「没出现」的排查与修复

## 30 秒状态

桌面应用里 Plugins → Free web (keyless) 页面**没有**配置入口，用户报告"页面没有出现"。查明真因不在
代码链路：宿主组图里有 `dsh-free-web/client.js`，浏览器半边也注册成功——但唯一入口是**插件行标题**
（`<button aria-label="Configure Free web (keyless)">`，视觉上只是标题 + 一个 › 箭头），作者自己
都没找到。修复：把同一个 picker 再注册进 `plugins.bundle.config`（键 = 包名 `dsh-free-web`），
打开插件页就能看到 Search engines 卡片，不用再点行标题；README 同时收敛（插件页描述就是 README，
之前 212 行把卡片挤到折叠线以下）。

## 怎么查到的（可复现的读数）

1. 拿不到桌面页面（`34553` 对普通浏览器回 `403 Browser access is disabled`，Electron 的 renderer
   token 只在主进程内存里），于是复制 desktop profile 到隔离 home 起 web 实例：
   `DSH_HOME=$PWD/.dsh-home dsh --profile desktopprobe --no-open --port 0`
   （复制后 `node_modules/dsh-free-web` 是相对 symlink，要改成绝对路径，否则
   `cannot resolve profile bundle`）。
2. 拉 `/`（带 token + cookie jar）→ 内联的 `__DSH_BOOT__` 里确有
   `dsh-free-web/client.js&rev=…`：**宿主组图没问题**。
3. 临时浏览器插件 `.probe/client-debug`（`dsh.client` 客户端半边，6 秒后 `console.log`）在页面里读到：
   `entries.failures=[]`、`served=[…,"free-web"]`、`rowConfig=["dsh-free-web#free-web"]`：**浏览器半边
   也注册成功**。
4. Firefox（WebDriver BiDi，`.probe/bidi.mjs`）点 Plugins → 卡片 → 行：
   `[aria-label^="Configure"]` 点开后 `[data-plugin-row-detail="dsh-free-web#free-web"]`、
   `[data-free-web]` + 8 个 `[data-engine]` 全在，**页面是好的**。
5. 因此结论是入口问题：行标题不是可识别的按钮（正文里根本没有 "Configure" 字样）。

## carry

- 桌面应用里的旧页面要**重载一次**（boot graph 是内联在 HTML 里的，`dsh.client` 只在 Host 启动时组图；
  `closeToTray: true` 时关窗口不重启 Host）。重载后插件页应直接出现 Search engines 卡片。
- 若仍不出现：先看 `~/.dsh/logs/desktop-next*.jsonl` 里有没有 `ClientPackageCompositionError`；
  再用复制 profile 的办法复核一次（`.dsh-home/profiles/desktopprobe`）。

## 坑

- `renderSlot('plugins.row.config')` 的入口在 DOM 里是 `button[aria-label="Configure <title>"]`，
  **可见文本里没有 "Configure"**——用 `textContent` 找会扑空，得用 aria-label。
- `plugins.bundle.config` 的 slot props **不带** `form`：bundle 级配置自己 `configForms.get(ns)`；
  `configForms.get()` 返回的是 controller（`getSnapshot/subscribe/mutate`），不是行页那种
  `{state, mutate}` 形状，要自己转。
- 复制 profile 到别的 home 时 `link:` 依赖是相对 symlink，必须改绝对，否则整个 bundle 被跳过。
- 隔离实例的 `ss -ltnp`/`ps | grep <名字>` 会匹配到自己这条 bash 命令行（`xargs kill` 把 shell 杀了两次），
  按端口取 pid。
