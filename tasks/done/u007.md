## 坑
- `process.env` 的键在 Linux 上大小写敏感：只认 `DSH_FREE_WEB_ENGINES` 全大写；proxy 那套「小写优先、再大写」是 curl 的宽容，别照搬到自定义变量上（测试里已固定这一行为）
- `resolveEngines([])` 不是「空池」而是「默认池」（`Array.isArray && length > 0` 才用传入值）→ 想验证「不挂载 search provider」必须传未知 id，而不是空数组
- `scripts/smoke.mjs` 原来把引擎数组写死，env 覆盖在脚本里不生效 → 脚本同源走 `enginesFromEnv()`，否则「改 env 再 smoke」会给出假阳性
